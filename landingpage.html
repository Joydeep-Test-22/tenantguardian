Security & Privacy

Your data never leaves
Microsoft's boundary.

Built on zero-trust principles. No servers, no databases, no data transmission. TenantGuardian AI is a browser-side application that calls Microsoft's own APIs directly.

Microsoft Entra ID Authentication

All authentication handled by Microsoft's own identity platform. TenantGuardian never sees or stores your credentials.

Zero Data Storage

No database, no backend server, no data persistence. All data lives in your browser session and is cleared when you close the tab.

Role-Based Access Control

Admin role gets full AI access. Viewer role sees all data but no AI features. Enforced via Microsoft Entra App Roles — not client-side.

Cloudflare Proxy for AI

AI token stored in Cloudflare's encrypted environment — never in the browser, never in source code. Enterprise-grade secret management.

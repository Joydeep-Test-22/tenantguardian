AI Scoring Engine
Phi-4 Llama 3.3 70B analyses each user's activity pattern and assigns an intelligent waste score — not just rules
How AI Scoring Works
llama-3.3-70b · phi-4 · free
The scoring engine analyses each user's complete activity profile across Exchange, Teams, SharePoint, and OneDrive — then reasons about the combination of signals, not just individual zeros. A user with no Exchange emails but active Teams usage is a valid collaboration-first worker — not a wasted licence. A user inactive across all services for 85+ days is a clear reclaim candidate. Borderline cases are flagged for human review, not auto-reclaimed — eliminating costly false positives. Results are significantly more accurate than rule-based thresholds and can be refined further with the AI narrative feature.
